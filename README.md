# COMMAND GRID — 統合戦線

軍事記号をモチーフにした、初心者向け同時命令型カードゲームのNiceGUI UIプロトタイプです。

## 収録画面

- ホーム / 初心者向け導入
- 3手順だけの遊び方と、必要なときだけ開く詳細用語集
- 最初の6枚だけを表示する初心者カード画面
- 参考画像201セルを用途・解放段階・個別表示ID付きで管理する全記号ライブラリ
- 全カード検索と詳細説明
- デッキ編成と初心者向け分析
- 対戦ロビー / フレンド招待
- 操作できる三戦線の対戦盤
- プロフィール / プレイ記録
- 初心者・アクセシビリティ設定

初心者向け画面は「1画面1目的・主ボタン1個」を基準にしています。記録、詳細な解決順、戦闘ログ、全カード、全記号は折りたたみまたは別画面へ分離しています。

## ローカル起動

Python 3.12以降を用意し、仮想環境内で次を実行します。

```bash
pip install -r requirements.txt
python main.py
```

ブラウザで `http://localhost:8080` を開きます。

## Render

リポジトリ直下の `render.yaml` をBlueprintとして読み込めます。`STORAGE_SECRET` はRender側で自動生成されます。

現段階のデッキと対戦状態はUI検証用のユーザーストレージです。本番のオンライン対戦ではPostgreSQLを正本とし、認証・マッチング・対戦処理をサーバー側へ移します。
