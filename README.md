# COMMAND GRID — 統合戦線

軍事記号をモチーフにした、初心者向け同時命令型カードゲームのNiceGUI UIプロトタイプです。

## 収録画面

- ホーム / 初心者向け導入
- 5分でわかる遊び方・用語集
- カード図鑑と詳細説明
- デッキ編成と初心者向け分析
- 対戦ロビー / フレンド招待
- 操作できる三戦線の対戦盤
- プロフィール / プレイ記録
- 初心者・アクセシビリティ設定

## ローカル起動

Python 3.12以降を用意し、仮想環境内で次を実行します。

```bash
pip install -r requirements.txt
python main.py
```

ブラウザで `http://localhost:8080` を開きます。

## Render

リポジトリ直下の `render.yaml` をBlueprintとして読み込めます。`STORAGE_SECRET` はRender側で自動生成されます。

現段階のデッキと対戦状態はUI検証用のユーザーストレージです。本番のオンライン対戦ではPostgreSQLを正本とし、認証・マッチング・対戦処理をサーバー側へ移します。

## 表記について

本作の部隊・記号・編制は、実在する軍事記号を参考にゲーム向けに簡略化したものです。実際の組織や作戦を正確に再現する教育資料ではありません。
