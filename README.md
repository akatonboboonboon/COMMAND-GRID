# COMMAND GRID — 統合戦線

軍事記号をモチーフにした、初心者向け同時命令型カードゲームです。Python / NiceGUIで動作し、1人用演習とオンライン1対1対戦の両方を遊べます。

## 遊べる内容

- 3戦線・6ラウンドの対戦と完全な勝敗判定
- 1人用の初心者演習（決定論的AI）
- カジュアル / ランクのオンライン待ち合わせ
- 6文字の合言葉によるフレンド対戦
- お互いの命令を隠したまま送信し、両者が揃った時だけ同時解決
- 一時切断からの再接続、待機切れの自動整理、退出時の不戦勝・不戦敗
- 結果の重複記録防止
- 制圧・支援・偵察・補給・機甲ボーナス
- カード収集、最大12枚のデッキ編成、大隊・旅団・師団の編制表示
- 対戦ごとのカード1枚・記号最大12種類の解放
- 201種類の記号図鑑と、解放済み記号のプロフィール章設定
- 戦績、勝率、任務点、最近の対戦履歴
- 初心者説明、確認画面、ログ、高コントラスト、文字サイズなどの永続設定

カードの兵科は「仕事」、大隊・旅団・師団は「表示する規模」です。編制規模だけでカードが強くなることはありません。

## 画面

- ホーム
- 3手順の遊び方 / 詳細用語集
- 基本カード / 全カード図鑑
- 201種類の全記号ライブラリと参照早見表
- デッキ編成 / 編制規模
- 演習、オンライン待機、フレンド部屋
- AI対戦盤 / オンライン対戦盤
- プロフィール / 戦績
- 設定 / アクセシビリティ

## ローカル起動

Python 3.12以降を用意し、仮想環境内で実行します。

```bash
pip install -r requirements.txt
python main.py
```

ブラウザで `http://localhost:8080` を開きます。オンライン対戦の確認は、通常ウィンドウとシークレットウィンドウなど、別々のブラウザセッションで行えます。

## テスト

```bash
python -m unittest discover -s tests -v
```

ゲームルール、保存データ移行、報酬、AI対戦、オンライン待ち合わせ、友人コード、秘匿情報、再接続、戦績の一度だけの記録をテストしています。

## Render

リポジトリ直下の `render.yaml` をBlueprintとして読み込めます。既存サービスを手動設定する場合は次の値です。

- Build Command: `pip install -r requirements.txt`
- Start Command: `python main.py`
- Health Check Path: `/healthz`

オンラインの待機列と進行中の対戦は、1つのRenderプロセス内で共有します。そのためインスタンス数は1のままにしてください。カード、設定、戦績などはNiceGUIのユーザーストレージへ保存されますが、無料Renderではローカルファイルが永続化されません。スリープ、再起動、再デプロイ時には、進行中の対戦とユーザーデータがリセットされます。

長期運用ではPostgreSQLを接続し、ユーザーデータと対戦の正本を外部へ移してください。複数インスタンス運用では、待機列と通知にも共有データストアが必要です。ゲームルールはUIから分離した `game_engine.py` にあるため、保存先を変更してもルールを作り直す必要はありません。
